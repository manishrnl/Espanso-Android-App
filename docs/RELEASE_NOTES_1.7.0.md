# rnl espanso 1.7.0

Release date: June 11, 2026

## New

- Opt-in password-field expansion through the bundled rnl espanso keyboard
- System, Light, and Dark global theme choices
- Guided Android restricted-setting setup
- In-app setup and troubleshooting guide
- In-app privacy policy and developer/social pages
- Instagram, Facebook, GitHub, website, and phone actions

## Improved

- Premium Settings layout with padded, colored action icons
- Premium folder creation dialog
- Clear Position and Template strategy explanations in the shortcut editor
- Updated accessibility and privacy disclosures

## Technical notes

- Accessibility expansion continues to ignore secure password fields because
  Android masks that text from accessibility services.
- Secure-field expansion is disabled by default and works only through the
  bundled keyboard after explicit confirmation.
- Package name remains `com.manishrnl.espansoandroid`.
- Release version is `1.7.0` with `versionCode 9`.
